# Italy Cookie Choices documentation

Italy Cookie Choices asks the consent of your visitors before the cookies that are not necessary, and blocks the third party scripts, videos and maps until the consent to their category.

[Leggi la documentazione in italiano](it/README.md).

- [Blocking the third parties](blocking.md): the vendors, the placeholders and the compatibility mode.
- [Consent log](consent-log.md): how the consents are demonstrated.
- [Multilingual sites](multilingual.md): WPML, Polylang and the other plugins.
- [Upgrading from 2.x](upgrade-3.0.md): what changes with the version 3.0.

## For the developers

- [Integrations](integrations.md): Google Consent Mode v2, the consent API, the events to block a script, add a vendor or change the texts.

## Requirements

- WordPress 6.5 or later
- PHP 8.2 or later
